## Overview

Returns a page of your subscriptions. Use it to reconcile your own records, find a customer's subscription, or list the ones about to end.

<Note>
  Each item is a [Subscription object](/api/endpoints/get-subscription#the-subscription-object). All amounts are in **cents**.
</Note>

## Authentication

This endpoint requires your **Secret API Key** (server-side only). See [Authentication](/api/authentication) for details.

```bash
Authorization: Bearer sk_live_xxxxxxxxxxxx
```

## Query Parameters

<ParamField query="status" type="string">
  Filter by status: `active`, `past_due`, `canceled`, or `canceling` — subscriptions not canceled yet but scheduled to end at `current_period_end` (`cancel_at_period_end: true`). Any other value is ignored.

  `active` also returns subscriptions scheduled to end (they stay `active` until then), and `canceling` covers both `active` and `past_due` subscriptions scheduled to end.
</ParamField>

<ParamField query="search" type="string">
  Case-insensitive partial match on the subscription ID, customer, customer email or `order_id` (first 100 characters used).
</ParamField>

<ParamField query="customer" type="string">
  Exact customer identifier, as passed in `customer` when creating the signup session.
</ParamField>

<ParamField query="page" type="integer" default="1">
  Page number, starting at 1.
</ParamField>

<ParamField query="per_page" type="integer" default="20">
  Results per page, up to `100`.
</ParamField>

<ParamField query="sort_by" type="string" default="created_at">
  `created_at`, `current_period_end`, `amount` (your price) or `unit_amount` (what the customer pays). Any other value falls back to `created_at`.
</ParamField>

<ParamField query="sort_order" type="string" default="desc">
  `desc` or `asc`.
</ParamField>

## Response Fields

<ResponseField name="data" type="array" required>
  Subscriptions of this page. See [the Subscription object](/api/endpoints/get-subscription#the-subscription-object).
</ResponseField>

<ResponseField name="total" type="integer" required>
  Number of subscriptions matching the filters, across all pages.
</ResponseField>

<ResponseField name="page" type="integer" required>
  Current page.
</ResponseField>

<ResponseField name="per_page" type="integer" required>
  Page size actually applied.
</ResponseField>

## Example Requests

<CodeGroup>

```bash cURL
curl "https://api.payviox.com/subscriptions?status=active&customer=customer_abc123&per_page=50" \
  -H "Authorization: Bearer sk_live_xxxxxxxxxxxx"
```

```javascript Node.js
const params = new URLSearchParams({
  status: 'canceling',          // scheduled to end at current_period_end
  sort_by: 'current_period_end',
  sort_order: 'asc',
});

const response = await fetch(`https://api.payviox.com/subscriptions?${params}`, {
  headers: { Authorization: `Bearer ${process.env.PAYVIOX_SECRET_KEY}` },
});

const { data, total } = await response.json();
console.log(`${total} subscriptions ending soon`);
```

```python Python
import os
import requests

response = requests.get(
    'https://api.payviox.com/subscriptions',
    params={'status': 'past_due', 'page': 1, 'per_page': 100},
    headers={'Authorization': f"Bearer {os.environ['PAYVIOX_SECRET_KEY']}"}
)

page = response.json()
for subscription in page['data']:
    print(subscription['id'], subscription['customer'])
```

</CodeGroup>
