## Overview

Stops the renewals of an `active` or `past_due` subscription. By default the subscription ends at the end of the period the customer already paid for; pass `at_period_end: false` to end it immediately — this also works on a subscription already scheduled to end.

| | `at_period_end: true` (default) | `at_period_end: false` |
|---|---|---|
| Further charges | None after `current_period_end` | None, from now — unpaid Stripe invoices of the subscription are voided, so no retry can charge the customer |
| `status` right after the call | Unchanged (`active` or `past_due`), with `cancel_at_period_end: true` | `canceled` |
| Can be undone | Yes, with [Resume Subscription](/api/endpoints/resume-subscription) until the period ends | No |
| `cancel_requested_by` | `api` | unchanged |
| `subscription_canceled` webhook | When the period ends | Right away |
| Refund of the current period | — | None (no automatic refund) |

<Tip>
  Customers can cancel by themselves (at period end only) from the `management_url` of their subscription — you don't need to build a cancellation flow. See [Let customers manage their subscription](/guides/subscriptions#let-customers-manage-their-subscription).
</Tip>

## Authentication

This endpoint requires your **Secret API Key** (server-side only). See [Authentication](/api/authentication) for details.

```bash
Authorization: Bearer sk_live_xxxxxxxxxxxx
```

## Path Parameters

<ParamField path="subscription_id" type="string" required>
  The Payviox subscription ID (`psub_...`).
</ParamField>

## Body Parameters

<ParamField body="at_period_end" type="boolean" default="true">
  `true` to end the subscription at `current_period_end`, `false` to end it now. Omitted, `null` or `""` mean `true`; any other non-boolean value returns `400`.
</ParamField>

## Response

The updated [Subscription object](/api/endpoints/get-subscription#the-subscription-object). Calling it again with `at_period_end: true` on a subscription already scheduled to end returns `200` without changing anything (and keeps its `cancel_requested_by`). You can still end immediately a subscription the customer scheduled to cancel.

## Example Requests

<CodeGroup>

```bash cURL (at period end)
curl https://api.payviox.com/subscriptions/psub_8fKx2LmQp4ZrT7vW1nYc3aBd/cancel \
  -H "Authorization: Bearer sk_live_xxxxxxxxxxxx" \
  -X POST
```

```bash cURL (immediately)
curl https://api.payviox.com/subscriptions/psub_8fKx2LmQp4ZrT7vW1nYc3aBd/cancel \
  -H "Authorization: Bearer sk_live_xxxxxxxxxxxx" \
  -H "Content-Type: application/json" \
  -X POST \
  -d '{ "at_period_end": false }'
```

```javascript Node.js
async function cancelSubscription(subscriptionId, { now = false } = {}) {
  const response = await fetch(
    `https://api.payviox.com/subscriptions/${subscriptionId}/cancel`,
    {
      method: 'POST',
      headers: {
        Authorization: `Bearer ${process.env.PAYVIOX_SECRET_KEY}`,
        'Content-Type': 'application/json',
      },
      body: JSON.stringify({ at_period_end: !now }),
    }
  );

  if (response.status === 503) {
    throw new Error('Stripe unreachable, retry later'); // safe to retry
  }
  if (!response.ok) {
    const { error, message } = await response.json();
    throw new Error(`${error}: ${message}`);
  }
  return response.json(); // Subscription
}
```

```python Python
import os
import requests

response = requests.post(
    'https://api.payviox.com/subscriptions/psub_8fKx2LmQp4ZrT7vW1nYc3aBd/cancel',
    headers={'Authorization': f"Bearer {os.environ['PAYVIOX_SECRET_KEY']}"},
    json={'at_period_end': True}
)

subscription = response.json()
print(subscription['cancel_at_period_end'])  # True
```

## Error Responses

<AccordionGroup>
  <Accordion title="400 -- Invalid at_period_end">
    `at_period_end` is neither a boolean nor empty (for example `"maybe"`). Omitted, `null` or `""` mean `true`.
  </Accordion>

  <Accordion title="401 -- Unauthorized">
    The API key is missing or invalid. This endpoint only accepts your **Secret API Key**.
  </Accordion>

  <Accordion title="404 -- Subscription not found">
    No subscription with this ID belongs to your business (`subscription_not_found`).
  </Accordion>

  <Accordion title="409 -- Already canceled">
    The subscription has already ended — nothing to do. A `409` with `The subscription changed meanwhile. Try again.` means it was modified during your request: retry.
  </Accordion>

  <Accordion title="502 -- Provider refused">
    Stripe refused the change. Nothing was changed on Payviox's side: contact [support@payviox.com](mailto:support@payviox.com).
  </Accordion>

  <Accordion title="503 -- Provider unreachable">
    Stripe couldn't be reached, or Stripe isn't configured on your account anymore. Nothing was changed: retry later.
  </Accordion>
</AccordionGroup>
